# АгроПрогноз — Кукуруза

Современная оболочка для прогнозирования погоды под выращивание кукурузы. Приложение представляет собой готовый каркас с интерактивной картой, панелью управления, анимацией загрузки, страницей результатов и полноценной базой данных сортов. Движок расчёта прогноза намеренно не реализован — для него подготовлена отдельная папка `calculations/`.

## Возможности

- Интерактивная карта мира: тёмная векторная подложка и спутниковый слой, масштабирование, перемещение, сетка координат, города, выбор точки кликом.
- Подсветка стран при наведении с всплывающей подсказкой.
- Регионы России: при увеличении отображаются 85 субъектов; при наведении показывается название, клик приближает карту и включает спутниковый вид, клавиша `Esc` возвращает обратно.
- Анимации: плавный «влёт» карты при запуске, пульсация выбранной точки, расходящиеся круги при клике, свечение границ.
- Панель управления в правом верхнем углу: координаты выбранной точки, дальность прогноза (1 / 3 / 6 месяцев), выбор даты.
- Календарь с переключением месяцев и лет; месяцы за пределами допустимого периода прогноза отображаются серым и недоступны.
- Кнопка «Спрогнозировать» запускает быструю анимацию загрузки с этапами скачивания погодных данных.
- Страница результатов: температурный график (мин/макс-диапазон и средняя), столбчатый график осадков, показатели (средняя температура, осадки, сумма активных температур, ГТК, влажность) с подсказками по методике, список рисков, переключатель «График / Таблица», сохранение отчёта с защитой от повторного сохранения.
- Вкладка «Данные»: светлый каталог скачанных метеонаборов — поиск, фильтры, сортировка, просмотр набора внутри раздела (закреплённая шапка, сортируемая таблица по дням с пагинацией), экспорт в CSV, удаление с объяснением последствий.
- Вкладка «Отчёты»: архив сохранённых результатов с поиском, фильтром по сорту, сортировкой по дате, открытием сохранённого результата без пересчёта и удалением отдельных записей.
- Вкладка «Сорта кукурузы»: справочник с поиском и фильтром по группе спелости, карточкой выбранного сорта и формой редактирования с валидацией и защитой несохранённых изменений.
- Светлое оформление только для этих разделов: карта сохраняет текущий вид без изменений.
- База данных сортов кукурузы (SQLite): создание, редактирование, удаление (с подтверждением), поиск, характеристики сорта.
- Все разделы обрабатывают состояния: загрузка, пусто, нет результатов поиска, ошибка чтения/записи, повреждённая запись.

## Структура проекта

```
electron/            оболочка Electron (main, preload, защищённый протокол app://)
src/                 интерфейс (HTML, CSS, JS) и ресурсы
  vendor/            локальные зависимости (Leaflet, sql.js, шрифт Inter)
  assets/            карта мира, регионы России, иконка
calculations/        папка расчётов (заглушка движка прогноза)
scripts/             вспомогательные скрипты (dev-сервер, ресурсы, защита кода)
build/               иконка приложения (ico, png)
.github/workflows/   сборка Windows EXE через GitHub Actions
```

## Запуск и сборка

```bash
npm install
npm run prepare:assets   # подготовка ресурсов и иконки
npm run preview          # предпросмотр в браузере
npm start                # запуск Electron-приложения
npm run test:smoke       # функциональные смоук-тесты светлых разделов (jsdom)
npm run protect          # сборка и обфускация кода интерфейса (ВНИМАНИЕ: перезаписывает исходники src/js)
npm run dist:win         # сборка portable EXE (требуется Windows)
```

Windows-исполняемый файл `AgroPrognoz-<версия>-portable.exe` собирается автоматически через GitHub Actions при пуше в ветку `arena/01a0854d-repo`. Перед упаковкой выполняется `npm run protect` — код интерфейса объединяется в один файл и обфусцируется.

Скачать готовую сборку:

- GitHub Releases: https://github.com/Igorr112323/-/releases/tag/v1.0.0
- Вкладка Actions (артефакт `AgroPrognoz-Windows-x64`)

## Защита кода

При сборке применяется обфускация JavaScript (переименование идентификаторов, шифрование строк, запутывание потока управления, разбиение строк). Весь код интерфейса объединяется в единый обфусцированный файл, отдельные исходные модули и файл движка расчётов в итоговую сборку не попадают. Приложение упаковывается в ASAR-архив. В production-сборке отключены DevTools и горячие клавиши отладки (F12, Ctrl+Shift+I/J/C). Анти-отладочные и аппаратные привязки уровня Themida/WinLicense требуют коммерческих лицензий и Windows-инструментов, поэтому в CI не применяются.

## Папка расчётов

Реализация алгоритмов прогнозирования подключается в `calculations/forecast_engine.js`. Интерфейс модуля:

```js
generateForecast(request) => {
  request: { lat, lon, varietyName, rangeMonths, targetDate },
  result:  { request, period, series, indicators, risks }
}
```

Сейчас модуль возвращает демонстрационные данные, чтобы интерфейс можно было увидеть в действии.

## База данных

Данные хранятся в SQLite (движок sql.js). Таблицы: `varieties` (справочник сортов), `forecasts` (сохранённые отчёты со снимком результата), `datasets` (скачанные метеонаборы, появляются после расчёта прогноза; хранятся компактно, старые наборы автоматически ограничены 30 записями). Отчёты и наборы независимы: удаление одного не трогает другое. В десктопной версии файл базы сохраняется в каталоге пользователя, в браузерном предпросмотре — в localStorage. Миграция — только добавление новой таблицы (`CREATE TABLE IF NOT EXISTS`), существующие данные не сбрасываются. Все запросы выполняются параметризованно, ввод пользователя валидируется перед сохранением.

## Источники данных

- Границы стран — Natural Earth (50m).
- Регионы России — Natural Earth (10m, admin-1).
- Векторная подложка — CARTO Dark Matter, © OpenStreetMap contributors.
- Спутниковый слой — Esri World Imagery (Esri, Maxar, Earthstar Geographics).
